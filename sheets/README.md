# Тракер за тегло и мерки

Файл: `Тракер_тегло_и_мерки.xlsx`

Съдържа два таба:
- **Тегло и снимки** — дневно тегло, тренировка/почивка, кардио, сън, основни мерки, линк към снимка. Колона A показва средно тегло за всяка седмица (изчислено автоматично с формула, групирано по 7 дни). Таблицата е предварително попълнена с 52 седмици напред, започвайки от следващия понеделник.
- **Мерки** — отделна таблица за месечни обиколки на тялото.

## Как да я отвориш в Google Sheets

1. Изтегли файла `Тракер_тегло_и_мерки.xlsx`.
2. Отвори [Google Drive](https://drive.google.com) → бутон **New → File upload** и качи файла.
3. След качването кликни два пъти върху него — Drive автоматично го отваря в Google Sheets.
4. (По желание) В Sheets избери **File → Save as Google Sheets** ако искаш да го конвертираш в постоянен Google Sheets документ вместо да остане .xlsx.

Цветовете, формулите и колоните се запазват напълно при отварянето в Google Sheets.
